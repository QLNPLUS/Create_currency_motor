# Currency Motor

Currency Motor adds a Create kinetic generator that consumes the owning player's Q-shop currency while running.

Supported targets:

- Forge 1.20.1
- NeoForge 1.21.1

The block uses a Void Motor-inspired model and owner avatar slot. Configure the per-RPM charge, maximum stress at 256 RPM, charge interval, and Q-shop currency id in the server config.
