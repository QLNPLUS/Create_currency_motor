# Changelog

## [0.1.0] - 2026-09-21

### Added

- Added the Create Currency Motor for Forge 1.20.1 and NeoForge 1.21.1.
- Added player avatar ownership display and owner-only slot interaction.
- Added configurable Q-Shop currency charging.
- Added decimal `currency_per_rpm` values from `0.1` to `1000000000000`.
- Added upward rounding of each final charge to a whole currency unit.
- Added the speed screen cost display in the form `256 金币 / 1秒` for the default Chinese locale.
